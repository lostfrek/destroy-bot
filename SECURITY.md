# Security Policy

## Версии

Бот работает в проде из ветки `main`, отдельные версии не поддерживаются.
Все исправления безопасности идут сразу в `main` и деплоятся
автоматически.

## Как сообщить об уязвимости

Нашли уязвимость (обход прав, доступ к чужим данным, выполнение кода через бота)?

1. Не создавайте публичный Issue.
2. Напишите через Security → Report a vulnerability в этом репозитории
   или напрямую [@lostfrek](https://github.com/lostfrek).

Отвечу в течение нескольких дней.
