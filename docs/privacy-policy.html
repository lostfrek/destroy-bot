Политика конфиденциальности Destroy Assistance

Последнее обновление: 2026.

Эта страница описывает, какие данные собирает и хранит Discord-бот Destroy Assistance, обслуживающий сервер семьи Destroy (Majestic RP, Orlando/RU18).

1. Какие данные собираются

  • Discord ID, имя пользователя и никнейм на сервере;
  • текущий ранг, история изменений ранга и предупреждений;
  • содержимое заявок и обращений, поданных через бота (включая указанные в формах текст, ссылки и даты);
  • состояние игровых AFK-сессий и приёма откатов с капта;
  • настройка личных уведомлений (включены/выключены).

2. Как используются данные

Данные используются исключительно для работы функций бота: рассмотрения заявок, учёта рангов и предупреждений, обработки обращений и связанных административных задач на сервере семьи Destroy. Автоматической обработки данных для иных целей не выполняется.

3. Где хранятся данные

Данные хранятся в базе MySQL, размещённой на платформе Railway, в приватном окружении, недоступном напрямую из интернета. Доступ к данным имеет только администрация, обслуживающая бота.

4. Передача третьим лицам

Бот не передаёт собранные данные третьим лицам. Единственный внешний сервис, с которым взаимодействует бот, — сам Discord, необходимый для его базовой работы.

5. Хранение и удаление

Данные хранятся до тех пор, пока это необходимо для работы сервера, либо до запроса участника на их удаление. Чтобы запросить удаление своих данных, обратитесь к администрации Discord-сервера.

6. Контакты

По вопросам обработки данных обращайтесь к администрации Discord-сервера семьи Destroy.
